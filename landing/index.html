Start here — local Mac

DMG always lands in ~/Downloads for now. Build, open, install.

  1. Get the code git clone https://github.com/Sparkey333/MirrorZ-Hecras.git && cd MirrorZ-Hecras · PR #2
  2. Optional — sync private materials ./scripts/sync_local_reference.sh "/Users/ansom/Downloads/HECRAS-Breaking Hecras Code"
  3. Dev env bash scripts/install_dev.sh && source .venv/bin/activate && pytest -q
  4. Build DMG → Downloads + open bash packaging/build_macos_dmg.sh writes ~/Downloads/MirrorZ-Hecras-0.5.1.dmg, opens the DMG, opens this page.
  5. Install Drag the app into Applications. Gatekeeper: right-click → Open → Open.
  6. First model In the app: File → Open → examples/beaver_creek.json → Run → Compute Profile. Help → Getting Started… / Key Sites… for the same checklist with live links.
